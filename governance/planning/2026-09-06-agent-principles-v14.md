## 你的原文(本頁權威)

> Agent 可以讓使用者開啟的內容,本質上都應該是 URL,URL 會分成「外部連結」(另開新視窗)以及「內部連結」
> 所有從 Agent 點開的內部連結(包括頁面和 Modal),都會在同頁面直接跳轉,**但 Agent 保持不動**。
> 換言之,所有內部連結的內容都能夠與 agent 同時運作。
> 只有開啟那些「沒有 URL 的 modal」才會整個蓋住 agent,沒有 URL 的 modal 是無法跟 agent 同時使用的,
> 所以,**URL 變得像是一種註冊器**,用來註冊「哪些內容可以跟 Agent 同時並行使用」

**本輪關鍵的一刀**:「能同時運作」是**內容的資格**(哪些內容有資格跟 agent 並存),
**不是版面的承諾**(當下擺不擺得下)。資格由 URL 決定、恆成立;版面由斷點決定。
所以「窄螢幕不得兩邊都能用」不是替原則開例外 —— 它本來就屬於另一條。

## 七條原則

每條各管一件事,不能互相推出,沒有一句在別處換句話說。

| 編號 | 管什麼 | 條文 |
|---|---|---|
| **A** | 內容資格 | agent 提供開啟的內容須能以 URL 定位。內部內容以**自己的** URL 取得協作資格;**沒有 URL 的 Modal 阻擋其餘介面,包含 agent。** |
| **B** | 呈現 | agent 開啟且無全域阻擋時,**寬螢幕**讓具資格的內容與 agent **並列可操作**;**窄螢幕**以抽屜蓋滿宿主,宿主暫不可操作。 |
| **C** | 導航 | 外部連結另開分頁;內部連結在目前分頁更新宿主,達成 URL 指定的內容、狀態與位置。只有這些要求**全都已經滿足**,才不動作。 |
| **D** | 連結責任 | agent 只提供系統查回或確認過的可點網址;自行生成而未經確認的顯示為純文字。目的內容的識別、存在與存取權限,由負責該內容的宿主判定。 |
| **E** | 持續使用 | **同次進入宿主期間**,agent 開關只由你明確的開關操作改變。導航、開合、遮擋與尺寸變化,不重設對話、草稿或閱讀位置,也不因此停止已開始的回覆。 |
| **F** | 生命週期 | 各分頁的 agent 工作狀態彼此獨立。初次進入、重新整理、新開分頁,**以及原分頁離開宿主後返回**,均重新初始化為關閉的新對話。 |
| **G** | 網址邊界 | 宿主 URL 只定位宿主內容,不攜帶也不還原 agent 的工作狀態。 |

**拿掉的東西**(全部不進原則):fab 當許可宣告、許可撤回與恢復、「不請自來的不准蓋板」、
「點連結先讓開」、以及「就是這一頁」那個精確文案。

| 部分 | 狀態 |
